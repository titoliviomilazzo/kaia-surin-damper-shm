## 프로젝트와 현재 단계

점성댐퍼는 움직임의 에너지를 소산하는 역할을 하며, SHM은 건물 진동과 댐퍼 주변 변위를 관측합니다. 가속도계 4대×3축, 와이어변위계, 현장 수집 PC·저장·웹 화면으로 구성됩니다. 보강 효과는 검토된 실측·공학 근거로 평가해야 합니다.

**2026-10-12 기준 현장 설치·시운전 전입니다.** 웹 화면이 열리는 것과 센서 실측이 들어오는 것은 별개입니다. 현재 위치 표시는 현장 확정 전 임시이며, 구조 안전 인증이나 검증된 보강 개선율을 제시하지 않습니다.

## 화면 사용법

1. 전체 링크를 열고 언어를 선택합니다. 기본 영어, English → ไทย → 한국어 순서의 최신 변경은 공개 서비스 반영이 필요합니다.
2. 요약·학교 모델에서 연결 상태와 위치를 봅니다. 위치 강조는 연결 성공 표시가 아닙니다.
3. 센서 그래프의 축·단위·표본 시각을 함께 봅니다. LIVE는 최신 수신, STALE는 오래된 자료, OFFLINE은 수신 불가입니다. 누락은 0값이 아닙니다.
4. 영문·태국어 보고서의 대상·기간·근거를 확인합니다. 유사시 샘플은 실제 사건 보고서가 아닙니다.
5. 연결 후 새로고침하거나 기다리면 자동 재조회합니다. 가속도 2초·변위 1초 간격이며, 현장 수집기·인터넷·중계가 모두 동작해야 합니다.

학교 관계자는 상태·보고서를, 엔지니어는 축/시간/교정/설치 근거를, 연구자는 필요한 자료의 기간·품질을 먼저 확인하세요. 공개 화면은 읽기 전용입니다. 영점 변경·장비 재시작은 할 수 없으며, 역할 탭은 권한 구분이 아닙니다. 계측 수신을 구조 안전 판정으로 해석하지 않습니다. 자동 구조 판정·경보/보고서 발송은 시운전 완료 기능으로 안내하지 않습니다.
